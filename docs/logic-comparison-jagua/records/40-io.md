## B8/B14 结论边界

- 本记录覆盖 5 个原先待记 Rust 文件；Pinned `io/ext_repr.rs` 和 `io/import.rs` 体现的 orientation 必填、旧字段拒绝、旋转角校验、item 禁洞、quality zone 部分 panic 等合同应继续作为 B14 的逐项执行输入。
- JSON DTO 可表示的 shape 不等同于 Importer 能接受的 shape；`ExtShape` 有 Polygon/MultiPolygon 变体，具体导入路径仍会返回错误或 panic/`unimplemented!`。
- Rust SVG 返回 `svg::Document` 且有若干 `unwrap/expect` 假设；C++ 返回 `Result<string>` 并显式校验选项/bounds。B8 的验收口径是几何和语义对照，不要求 SVG 字节完全相同。
- 本轮只做静态映射；没有生成/解析 JSON、渲染 SVG 或运行对拍。

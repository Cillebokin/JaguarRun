## 哈希口径

生成器 [freeze-baseline.ps1](tools/freeze-baseline.ps1) 对六个源树逐文件计算 SHA-256，并按规范化相对路径排序后计算树摘要：Sparrow Rust、jagua-rs 本地镜像、Cargo 实际解析的 jagua-rs checkout、JaguarCore、SparrowCore，以及 Sparrow 比较记录。源树哈希排除 .git、target、build、Debug/Release 输出、对象/预编译头和常见生成目录；测试 fixture 会收录，不受扩展名过滤。qmake Makefile、SparrowCoreTests.exe 和匹配的 JaguarCore DLL 作为单独构建产物记录路径、大小、修改时间和 SHA-256。

默认运行会拒绝覆盖 baseline-2026-10-09.json。需要比较后续工作区时，应指定一个新输出路径；除非用户明确决定重建基线，否则不对本文件使用 -Force。两个独立 manifest 的 sourceRoots.sha256 相同，才能说明纳入的源与 fixture 未变化；构建产物、工具链或 Cargo 锁变化仍须单独检查。

## 当前认证边界

该基线固定的是 Windows x64、当前 scalar RustReference feature 集，以及由该构建配置链接的 JaguarCore AVX2 产物。它没有认证其他操作系统/架构、其他 MSVC/Qt 版本、Rust SIMD feature 或未进入 manifest 的外部运行时。Cargo 缓存 checkout 的绝对目录属于本机解析位置，真正的内容身份由锁定 revision 与其文件摘要共同确定。
